# m3eGram — tdesktop × Material Design 3 Expressive

Приватный снапшот [telegramdesktop/tdesktop](https://github.com/telegramdesktop/tdesktop) (dev)
с патчем **MD3 Expressive**: единые 20dp-скругления у всех сообщений-пузырей
(20dp — «bold»-шаг шкалы форм M3 Expressive, старое значение 16dp).

## Что здесь

- Исходники tdesktop @ dev + применённый `patches/m3e-expressive.patch` (см. `Telegram/SourceFiles/ui/chat/chat.style`)
- `.github/workflows/build-linux.yml` — сборка Linux-бинарника официальным Docker-окружением
- `.github/workflows/build-windows.yml` — сборка Windows x64 (VS2026 на `windows-latest`), экспериментальная

## Как собрать

1. Получи **api_id** и **api_hash** (бесплатно, 2 минуты): https://my.telegram.org → *API development tools*.
2. Settings → Secrets and variables → Actions → New repository secret:
   - `TDESKTOP_API_ID` = твой api_id
   - `TDESKTOP_API_HASH` = твой api_hash
3. Вкладка **Actions** → выбери workflow → **Run workflow**:
   - *Build tdesktop Linux* — надёжный вариант (~3–5 часов), артефакт `tdesktop-m3e-expressive-linux`
   - *Build tdesktop Windows* — эксперимент (~2–4 часа), артефакт `tdesktop-m3e-expressive-win64`

Артефакт появится внизу страницы запуска (Build → Artifacts).

## Зачем api_id

Без `TDESKTOP_API_ID`/`TDESKTOP_API_HASH` клиент не пройдёт логин на серверах Telegram —
это требование MTProto, а не CI. Креды хранятся только в секретах твоего приватного репо.

## Обновление патча

Снапшот — одиночный коммит поверх upstream dev. Хочешь ещё «экспрессива» (больше радиусов,
шейпы) — правь `.style`/`.cpp` файлы в ветке и просто перезапускай workflow.

## Что уже переделано в исходниках (SourceFiles, без патча)

Правки лежат прямо в `Telegram/SourceFiles` и помечены комментарием `m3eGram` там, где это C++.

- **Список чатов** (`dialogs/ui/dialogs_layout.cpp`, `dialogs/dialogs_inner_widget.cpp`): активный и наведённый чат — скруглённая «пилюля» (secondary container) вместо заливки на всю ширину, ripple обрезается по форме. Токены: `dialogsRowPillRadius`, `dialogsRowPillSkip` в `dialogs.style`.
- **Поле ввода** (`chat_helpers.style`): `defaultComposeControls.radius` 12 → 28 (полная пилюля).
- **Радиусы по шкале M3 Expressive** (8 / 12 / 16 / 20 / 28) в: боксах, настройках, профиле/инфо, статистике, платежах, звонках, медиапросмотре и сторис, редакторе фото/видео, входе (intro), опросах, ИИ-композере, тостах, подсказках, превью и плашках в чате.
- **Кнопки** с локальным `radius` 4–8px (в т.ч. кнопка «Далее» при входе) приведены к пилюле.

## lib_ui (правится через lib-ui-md3.patch)

Рабочая копия для правок: `E:\Tipo zagruzki\piton\m3eGram\lib_ui-work` (git, база — коммит 993406d).
Патч пересобирается так: `git add -A; git diff --cached 993406d --output=<путь>\patches\lib-ui-md3.patch`.
Старая версия патча сохранена как `lib-ui-md3.patch.bak`.

Сделано поверх палитры/кнопок/боксов:

- **Переключатель** (`checkbox.cpp` + `defaultToggle`): M3-свитч 52×32 — пилюля-дорожка, ползунок растёт при включении, контур только в выключенном состоянии. Все производные стили наследуют; в меню — компактный 42×24.
- **Меню** (`menu_action.cpp`, `menu_multiline_action.cpp`): выбранный пункт — пилюля (inset 8px, радиус 12), ripple по той же форме. Токены `menuItemPillRadius` / `menuItemPillSkip`.
- **Всплывающее меню** радиус 8 → 20, тосты 8 → 16, важные подсказки 4 → 12.
- **Слайдер**: дорожка 3 → 4px, ползунок 9 → 12px.
- **Поля ввода**: индикатор фокуса 2 → 3px со скруглёнными краями (`input_field.cpp`). **Вкладки**: индикатор со скруглением 2px. Чекбокс и радио уже соответствуют M3 (заливка + галочка / точка), не менялись.
- **Кнопки в списках настроек** (`buttons.cpp/.h`, `SettingsButton`): подсветка при наведении — пилюля (токены `settingsButtonPillRadius` / `settingsButtonPillSkip`), ripple по той же форме через `prepareRippleMask`.
- **Выпадающие списки** (`innerDropdownRadius`): 8 → 16. Тень там рисуется универсальным `BoxShadow`, так что радиус менять безопасно.
- **Боковая панель папок**: активный пункт — пилюля уже в патче (`side_bar_button.cpp`). **Верхняя панель чата** оставлена плоской: по структуре уже M3 (круглые иконки-кнопки).
- **Боковая панель папок (исправление)**: фон кнопки теперь всегда закрашивается (раньше у активной папки оставалась чёрная рамка), активный пункт — скруглённая пилюля с отступом 4×2px и радиусом 16, ripple обрезается по ней.
- **Всплывающее уведомление о сообщении** (`window/notifications_manager_default.cpp`, `notifyRadius: 20px` в `window.style`): окно — скруглённая карточка. Углы задаются маской окна, а рамка 1px рисуется скруглённым контуром (вместо четырёх прямых линий) — и в самом уведомлении, и в поле ответа, и в кнопке «скрыть все». Работает только для встроенных уведомлений Telegram; нативные уведомления Windows оформить нельзя (в настройках уведомлений отключи «Нативные уведомления»).
- **Меню «Искать в…»** в списке чатов (`dialogsSearchInMenu`): радиус 8 → 20, чтобы совпадало с остальными меню.
- Цитаты в сообщениях 5 → 8, миниатюры файлов 4 → 8, кнопка расшифровки 4 → 8, кнопка выбора фото стикеров 8 → 12, таблицы в инфо 6 → 12.

## Блюр вместо полупрозрачности

Общий помощник в `lib_ui` (`ui/ui_utility.h/.cpp`): `Ui::BlurredBackdrop` / `Ui::BlurredWidgetBackdrop` — снимок виджета, уменьшенный в 4 раза и размытый (`Images::BlurLargeImage`, радиус 6). Рисуется растянутым на нужную область.

- **Затемнение под боксами, настройками и главным меню** (`ui/layers/layer_widget.cpp`): вместо плоского чёрного `layerBg` (50%) — размытый снимок окна + более лёгкое затемнение (×0.55). Снимок делается один раз при открытии, пока открыт хоть один слой, и сбрасывается после полного закрытия.
- **Превью стикеров / GIF по долгому нажатию** (`window/window_media_preview.cpp`): подложка `stickerPreviewBg` теперь лежит поверх размытого окна.

Не менялось (осознанно): `mediaviewBg` (92% непрозрачности — фактически сплошной), `toastBg` (90%), тени, ripple, оверлеи выделения, а также сервисные плашки в чате (`msgServiceBg`) и плашки поверх медиа — они рисуются прямо поверх обоев чата, и честный блюр там требует отдельного кэша обоев.

- Кнопка «Подтвердить вход» в списке чатов (`dialogsUnconfirmedAuthButton`) 12 → 20.
- Проверено и уже соответствует M3: поле поиска в списке чатов (полная пилюля), `ImageRoundRadius::Small/Large` (подтягиваются из `roundRadiusSmall/Large` = 8/16), радиусы кнопок.
